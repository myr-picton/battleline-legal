# Battle Line Legal

Public legal and account-deletion pages for the Android game Battle Line.

- Privacy Policy: https://myr-picton.github.io/battleline-legal/privacy/
- Terms of Service: https://myr-picton.github.io/battleline-legal/terms/
- Account deletion: https://myr-picton.github.io/battleline-legal/delete-account/

The site is Korean/English and is published with GitHub Pages from the `main` branch root.
